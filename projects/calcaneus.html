Posterior Facet Landmark Identification on the Calcaneus

Orthopedic Biomechanics Research · Automated anatomical landmark detection from 3D CT data
MATLAB CT Point Clouds Surface Analysis 3D Visualization Curvature Analysis

Overview

This project supports clinical research into subtalar joint mechanics following ankle arthrodesis in patients with ankle osteoarthritis. The goal was to build an automated pipeline that isolates the posterior facet of the calcaneus from 3D CT-derived surface models and identifies key anatomical landmarks — enabling consistent, repeatable measurements across patients.

Approach

  • 2nd principal curvature surface analysis applied to the original CT-derived calcaneal surface mesh to isolate the posterior facet region
  • Surface extrema detection to identify four anatomical points of interest on the posterior facet
  • Coordinate system alignment via medial-lateral midpoint analysis and vector cross products, later simplified by confirming both models shared a native coordinate system
  • Superposition of posterior facet data onto the full calcaneus model for visualization and verification

Results

  • Delivered reusable MATLAB code — processing a new patient requires only changing the input file name
  • Ensured consistency, automation, and reusability to support ongoing clinical research
  • Visualized and superimposed posterior facet landmarks onto full 3D calcaneus models for validation

Clinical context

Ankle arthrodesis (fusion) is a common surgical treatment for severe ankle osteoarthritis, but it can alter the mechanics of the subtalar joint below. Understanding how the posterior facet geometry changes across patients helps researchers study these downstream effects and may inform surgical planning and post-operative monitoring.
