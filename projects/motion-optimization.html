Robot Motion Speed Optimization via Data Point Reduction

Prosthetic Simulation · Comparing algorithms for trajectory compression
MATLABMotion CaptureNumerical MethodsData Reduction

Overview

Robot prosthetic simulations replay motion-capture trajectories, but raw data contains far more points than needed for smooth playback. This project compared three algorithms for reducing motion-capture data point counts while preserving trajectory fidelity, enabling faster prosthetic robot motion with minimal error.

Methods

  • Triangle Method: Iteratively removes the least significant data points using distance calculations and triangle area formulas, selecting points with minimal area contribution and tracking cumulative error
  • 2D Trapezoidal Integral Approximation: Projects motion-capture data onto a 2D vector space using dot products, then iteratively removes points contributing the least trapezoidal area
  • 3D Trapezoidal Integral Approximation: Extends the trapezoidal approach to 3D, interpolating points and calculating the area under the curve to minimize error while preserving data shape

Results

  • The Triangle Method was the most efficient in both speed and error minimization
  • 402 of 492 points (82%) were removed while keeping error minimal — sufficient for a realistic jumping jack simulation
  • The 2D Trapezoidal method had slightly higher error, and the 3D Trapezoidal method showed significantly more error at high removal counts

Takeaway

Simple geometric heuristics (triangle area) outperformed more mathematically complex integral-based methods for this application. The reduced trajectory maintained visual fidelity while dramatically improving playback speed — a practical result for real-time prosthetic simulation environments.
