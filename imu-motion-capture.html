Wireless IMU Motion Capture System

IHMC · 2026 · Real-time joint angle tracking, from sensor to skeletal model
ESP32 MPU9250 Madgwick Fusion PCA Calibration MuJoCo Python UDP I2C

Overview

A wireless IMU system that tracks lower-limb joint angles in real time. Four low-cost sensor nodes stream orientation data over WiFi to a live 3D skeletal model, computing hip, knee, and ankle angles with no wired connection to the body.

Hardware

Each node pairs a XIAO ESP32C3 microcontroller with an MPU9250 9-axis IMU, connected via I2C at 400 kHz. An FPC antenna provides the WiFi link. The full assembly fits in a compact, custom-fabricated enclosure worn on each body segment.

Software pipeline

  • Firmware: ESP32 + MPU9250 sample at ~330 Hz; gyro is filtered and Madgwick algorithm fuses accelerometer + gyroscope into orientation, streamed over UDP
  • Static calibration: Sensor held still — measures gravity direction to fix the vertical axis
  • Functional calibration: Person swings the joint — PCA on gyro data finds the joint's own rotation axis; one known-direction motion resolves the sign
  • Simultaneous zero: All segments zeroed together from one shared neutral pose
  • Live joint angle: Relative rotation between two segments, projected onto the calibrated axis

Four-segment system

The full system uses four sensors — pelvis, thigh, shank, and toe — each with its own calibration. The pelvis uses static (gravity) calibration only as a fixed reference. The other three use static + functional calibration via joint swings. All four sensors are zeroed together from one shared neutral stance.

Live output: knee flexion, ankle dorsiflexion, hip flexion, and hip ab/adduction — each the relative rotation between two adjacent segments, projected onto its calibrated joint axis.

Validation

Knee flexion angle was compared against an OpenSim skeletal reference, showing a repeating gait-like cycle that matches the expected joint pattern.

Skills gained

  • Embedded systems: I2C sensor interfacing, real-time ~330 Hz sampling, WiFi/UDP streaming
  • Signal processing: Madgwick sensor fusion, PCA-based axis calibration, quaternion/rotation math
  • Simulation: Real-time 3D modeling in MuJoCo, Java-based orientation viewer
  • Experimental methods: motion capture systems, EMG, force plates, humanoid robot operation
